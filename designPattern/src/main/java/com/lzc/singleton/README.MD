# 单例笔记

### 饿汉
不管用到与否，类装载时就完成实例化。
类加载到内存后就实例化一个实例，JVM保证线程安全（JVM保证每个class只会落到内存一次） 
#### 1.在静态成员变量的时候初始化
private static final Lzc01 INSTANCE = new Lzc01(); 
#### 2.静态代码块中进行new

### 懒汉
什么时候用，什么时候初始化。
#### 1.getInstance获取单例的时候，如果单例为null，才进行初始化
多线程访问的时候有可能会产生多个实例
#### 2.对getInstance方法加锁synchronized
影响性能
#### 3.对getInstance方法中实例化部分加锁synchronized
还是会产生多个实例
#### 4.对getInstance方法中实例化部分加锁synchronized,同时，实例化部分添加null判断

### 静态内部类实现
添加一个静态内部类，里面提供静态实例，getInstance获取单例的时候，直接获取内部类的里面的静态实例，由于加载外部类时不会加载内部类，这样可以实现懒加载。
